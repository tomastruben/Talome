# Completion Checklist

Before finishing, verify:

- research findings contain real source evidence, compatibility, license, and explicit reuse decisions
- primary use cases map to complete workflows and purposeful screens
- each screen has one user job, one primary action, and its relevant loading/empty/error/compact states
- the app spec is valid and complete
- compose services, ports, volumes, and env vars are internally consistent
- scaffold files exist when scaffold generation is enabled
- the output reflects Talome's design language
- every primary surface and meaningful interaction state was rendered in Talome dark mode, with readable charts/SVGs, visible focus, resolved semantic colors, and no black-on-black or transparent data marks
- the validation report contains explicit dark-mode evidence for the desktop window and supported compact/narrow behavior
- reused sources are recorded in metadata
- the result is specific to the user request, not a generic boilerplate
- the rendered primary workflow was exercised and compared with the accepted screen spec or visual concept
- the research, screen specification, and validation artifacts are marked complete
- the generated app is realistic enough to run or to be corrected with only small follow-up tweaks
