# UI engineering review — 3 October 2026

This pass used the signed-in instance at localhost:3000, source review, read-only browser DOM measurements, component tests, TypeScript, and a production build. It is not a completed visual audit: browser screenshots fail and click input times out. Dark/light visual comparison, opening every desktop window, resizing windows by dragging, and live dialog interaction remain unverified.

## Changes

- Services: fit names and actions into narrow content; hide secondary memory values below 28rem; retain status/CPU from 36rem. Make service names keyboard-accessible buttons. Keep action buttons visible on touch and keyboard focus, and use 44px touch targets.
- Audiobooks: library cards are native buttons with a visible keyboard focus ring; Enter opens the detail route. Cover art is decorative within the named button.
- Navigation: prevent 44px touch Back buttons from being clipped by 28px animated wrappers. Prefer the page's declared drilldown title, including AI Agents.
- Mobile navigation and standard dialogs: limit height to the available dynamic viewport and allow internal scrolling, so short screens can reach the final controls.
- Native apps: budget layouts and comparison tables respond to their allocated block/card width. They no longer assume that the browser viewport equals the space available inside a desktop window or grid.
- Backups: resolve native icon identifiers into Hugeicons instead of showing raw metadata strings; broken images fall back to the glyph.

## Header and native subsection follow-up

Source review covered the shared desktop shell and page toolbars, including native apps, Services, Automations, Files, Share, configuration and stack detail. The six local native app specifications declare 14 surfaces across Budget Compass, Strategy Intelligence, Weather Guard, Server Weather, Stopwatch and LiteMol.

- Native desktop navigation uses the shared window sidebar when room allows, with a compact view menu at smaller window widths. It removes the extra tab row in embedded windows; classic/mobile retain named tabs. The selected view is encoded in `?view=`, follows navigation/history, and is retained when returning from the Assistant.
- Native surface layouts now honor dashboard, list and detail declarations instead of treating every section as a dashboard grid. Cards, inset materials, chart breakpoints and typography follow shared tokens and container sizes.
- Native primary actions stay in the header. Repeated copies in Actions cards are removed, empty cards disappear, and remaining card actions are secondary. This affects Strategy Intelligence, Stopwatch and LiteMol without editing their stored specs.
- Services replaces two filter tab strips with a compact filter menu in desktop windows. Updates are a secondary icon action; expanding search hides secondary controls.
- Automations, Files and Share declare compact single-row toolbars. Files keeps the permitted search-scope accessory row while searching; its collapsed search button no longer has an overlapping shortcut/clear control. Share moves selection counts to the window status bar and retains full accessible action names.
- Configuration and stack detail defer their embedded titles to the shell instead of rendering a second visible page heading. Title overrides are cleared on unmount.
